Stage 1.
Intent Classifier
  • intent: doc_qa / doc_summary / doc_compare / file_search / web_search / chat
  • mode: file_mode / folder_mode / general_chat
  • confidence · needs_context · web_search_enabled · response_language · selected_files

▼
Stage 2.
History Selector
  • needs_context=true + chat_history 존재 시에만 실행
  • selected_history · selected_indices · selection_reason (관련 대화 턴 선택)
↳ 조건 미충족 → skip · chat → Generator / 그 외 → Rewriter
▼
Stage 3.
Query Rewriter
  • optimized_query · resolved_query · keywords
  • search_filter: {author, extension, date_from, date_to}
  • 프롬프트 분기: search_optimization(doc_qa·web_search) / file_filter(file_search)
↳ web_search → Web Search Setup · 그 외 → Planner
▼
Stage 4.
Planner
  • complexity: simple / complex
  • tasks: [{id, agent, query, description, depends_on, parameters}]
  • summary · original_query
  • agent: document_retriever(→file_rag/folder_rag) · file_search · summary · compare · file_resolver
▷ Web Search Setup — web_search intent 시 Planner 대체 (rewriter→web_search_setup)
▼
